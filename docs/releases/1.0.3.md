# Notaría VE 1.0.3

## Correcciones y mejoras
- El rol de consulta ya no muestra el acceso al asistente de redacción con Gemini, evitando ofrecer una acción que no está autorizada para ese perfil.
- El selector de modalidad de honorarios y el importe personalizado quedan deshabilitados para el rol de consulta, en coherencia con los permisos de escritura aplicados por IPC.
- Se conserva la identidad visual original de Notaría VE, incluidos los logos horizontales, el icono de Windows y el favicon incorporados en la versión anterior. Esta actualización no sustituye ni rediseña esos recursos.

## Configuración de Gemini
La aplicación requiere que cada usuario configure su propia clave de Google AI Studio. La clave no se incluye en el instalador y su uso continúa sujeto al consentimiento explícito y a los límites y condiciones de Google.

## Honorarios
US$60 continúa siendo un importe fijo de referencia configurable, no un mínimo legal universal. El profesional debe comprobar el tabulador vigente correspondiente al servicio.

## Instalador
El instalador de Windows se distribuye sin firma digital Authenticode. Windows puede mostrar una advertencia de editor no verificado. El archivo `SHA256SUMS.txt` acompaña al EXE para comprobar su integridad.

# Notaría VE 1.0.4

## Asistente de redacción con Gemini
- Cada solicitud exige una autorización expresa nueva; la autorización se consume al iniciar el envío y vuelve a quedar desmarcada al terminar, incluso si la solicitud falla.
- Los errores de red, tiempo de espera, cuota, clave y disponibilidad del modelo muestran mensajes seguros sin reproducir cuerpos de respuesta del proveedor.
- La bitácora conserva únicamente el proveedor y las longitudes de los textos; no registra cláusulas, instrucciones ni API keys.
- Se conserva la clave cifrada localmente mediante el almacenamiento seguro del sistema operativo. No se añade persistencia remota.

## Presupuesto y honorarios
- El selector permanece visible en el flujo de Presupuesto: 3 % de la cuantía declarada, importe fijo de referencia de US$60 o monto libre definido por el profesional.
- El importe de US$60 es una referencia configurable seleccionada expresamente, no un mínimo legal universal. El modo 3 % y el monto libre no se modifican ni elevan automáticamente.
- Se bloquean los resultados, la impresión y la exportación cuando la tasa BCV, la cuantía, las páginas, los otorgantes o el honorario libre no son válidos.
- Se amplían las pruebas de cálculo, conversión y validación.

## Identidad y distribución
- Se mantienen los recursos originales de Notaría VE: logos horizontales, icono de escritorio y favicon. El proceso de compilación falla si falta el paquete original de identidad.
- Versión de aplicación, metadatos del ejecutable Windows, nombre del instalador y etiqueta de Release se derivan de la versión del paquete.

## Privacidad y advertencias
Gemini es un proveedor externo. Google indica que el contenido enviado mediante el nivel gratuito puede utilizarse para mejorar sus productos. Antes de cada envío, el usuario debe revisar este aviso y evitar datos de clientes, secretos profesionales, datos personales o información confidencial innecesaria. La respuesta generada es un borrador que requiere revisión profesional. Los datos de clientes, expedientes y documentos continúan en SQLite local.

US$60 se ofrece como importe fijo de referencia configurable; no se presenta como mínimo legal universal. El profesional debe comprobar el tabulador vigente correspondiente al servicio.

## Instalador
El instalador Windows NSIS x64 se publica como artefacto de GitHub Actions y como archivo de esta Release, acompañado de SHA256SUMS.txt. La ejecución de CI verifica los metadatos y el SHA-256. El instalador no tiene firma Authenticode.

# Notaría VE 1.0.2

## Novedades
- Asistente de redacción jurídica conectado a Gemini Flash. La clave API se guarda cifrada en el equipo y cada generación exige consentimiento explícito.
- Selector de honorarios profesionales para presupuestos: 3% de la cuantía, monto fijo de referencia de US$60 o monto libre. Aplicación uniforme a los ocho tipos de acto, conversión BCV, desglose, impresión y exportación Word.
- Identidad visual original aplicada: logos horizontales para fondos claros y oscuros, icono de escritorio Windows y favicon originales.
- Metadatos del ejecutable Windows actualizados: nombre de producto, compañía, descripción, marca registrada, versión y copyright.
- 30 pruebas automatizadas; validación SQLite, TypeScript y compilación de renderer y paquete Windows.

## Configuración de Gemini
La aplicación requiere que cada usuario configure su propia clave de Google AI Studio. El acceso gratuito tiene límites de uso y condiciones de privacidad propias de Google; el texto se envía a Google únicamente después de aceptar el consentimiento en la aplicación. No se incluye una clave en el instalador.

## Honorarios
US$60 se ofrece como importe fijo de referencia configurable; no se presenta como mínimo legal universal. El profesional debe comprobar el tabulador vigente correspondiente al servicio.

## Instalador
El instalador de Windows se distribuye sin firma digital Authenticode. Windows puede mostrar una advertencia de editor no verificado. El archivo `SHA256SUMS.txt` acompaña al EXE para comprobar su integridad.
